## 📖 About the Project

This repository was created as part of my journey to learn **Git and GitHub**.

Git is a distributed version control system that allows developers to track changes to their code.

GitHub is a platform that allows developers to store Git repositories online and collaborate with other developers.

This repository is being used to practice the basic GitHub workflow:

```text
Create Repository
       ↓
Clone Repository
       ↓
Create / Edit Files
       ↓
Git Add
       ↓
Git Commit
       ↓
Create Branch
       ↓
Make Changes
       ↓
Push Branch
       ↓
Pull Request
       ↓
Merge
